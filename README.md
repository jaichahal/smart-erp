# Smart ERP

A proprietary ERP for a UAE trading and light-manufacturing company: governed documents, a
tamper-evident ledger, approvals from the phone, and a single on-premises NUC as phase 1
production. Built as a Go modular monolith with a React console and native Android and iOS apps,
by a team of AI agents working in parallel from one written specification.

## Read first

- `docs/spec/` is the source of truth. Start with `docs/spec/00-README.md`.
- `docs/spec/10-execution-playbook.md` explains how the spec becomes software: targets, stack,
  agent protocol, waves.
- `CONTRIBUTING.md` is the playbook's operating protocol as instructions to a contributor.
- `WAVE1.md` holds the seven Wave 1 hand-off cards with ready-to-paste agent prompts.
- `docs/spec/04-api-contracts.md` governs `contracts/`; contracts change before code (ADR-09).

## Quick start (Apple Silicon Mac)

Requirements: Docker Desktop (Compose 2.24+), Go 1.27.1, `just`, `golangci-lint` 2.14, `sqlc`,
`goose`, `oapi-codegen`, `gh`. `brew install go golangci-lint sqlc goose oapi-codegen just age`.

```sh
just up          # compose stack, dev profile: postgres, valkey, minio, zitadel, caddy, mailpit, push-sink
just migrate     # goose migrations from apps/api/migrations
just template    # erp_template, cloned per test run
just db me       # optional: your own erp_test_me database; export the line it prints
just test-all    # go test ./... -race; each package clones erp_template
just lint        # golangci-lint with the module boundary rules
```

Environment used by the tools and tests:

```
ERP_ADMIN_DATABASE_URL=postgres://postgres:postgres@localhost:5432/postgres?sslmode=disable
ERP_MIGRATOR_DATABASE_URL=postgres://erp_migrator:erp_migrator@localhost:5432/erp?sslmode=disable
ERP_DATABASE_URL=postgres://erp_app:erp_app@localhost:5432/erp?sslmode=disable
```

## Layout

```
smart-erp/
  docs/spec/                 the specification, 00 to 10
  contracts/
    openapi/openapi.yaml     OpenAPI 3.1, machine form of docs/spec/04
    events/                  JSON Schema for outbox, socket and push events, with examples
    fixtures/canonical/      canonical JSON and hash vectors (generated by the Go kit)
  apps/
    api/                     Go module github.com/jaichahal/smart-erp/apps/api
      cmd/                   api, worker, scheduler, migrate, pushsink
      internal/kit/          shared kit: apierr, idempotency, ifmatch, rls, audit, canon,
                             immutable, outbox, testdb, httpx, oapi, config, obs
      internal/<module>/     identity, authz, approvals, audit, ledger/periods, clocks,
                             notifications, journeys, ... one owner each
      migrations/            goose SQL migrations (Track B)
      .golangci.yml          lint and module boundary rules
    console/                 React
    android/                 Kotlin, Compose
    ios/                     Swift, SwiftUI
  packages/tokens/           design tokens exported to Compose, SwiftUI, CSS
  deploy/
    compose/                 docker-compose.yml, profiles dev and prod, Caddyfile, postgres-init
    systemd/                 units and timers for the NUC
    nuc/                     bootstrap and runbooks
    scripts/                 backup.sh, restore.sh, anchor.sh, verify-chain.sh
  .github/
    workflows/               ci.yml, build.yml, contracts.yml
    CODEOWNERS               directory to track mapping
    pull_request_template.md
  Justfile                   every command contributors and CI use
  CONTRIBUTING.md            operating protocol
  WAVE1.md                   Wave 1 hand-off cards
```

## CI

| Workflow | Trigger | Jobs |
| --- | --- | --- |
| `ci.yml` | PR, push to main, merge queue | lint, test (PostgreSQL 16 service), licence (go-licenses), sbom (syft) |
| `build.yml` | push to main, tags `v*` | multi-arch images for api, worker, scheduler, migrate, pushsink to `ghcr.io/jaichahal/smart-erp/<cmd>` |
| `contracts.yml` | PR | openapi-lint, event-schema, openapi-drift, contract-first, immutable-change, spec-traceability |
